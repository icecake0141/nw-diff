## English

### Purpose
This folder separates startup procedures by use case so first-time users can find the right steps quickly.

### Guides
- [Quick Test Startup](./STARTUP_QUICK_TEST.md): Fastest trial startup for first-time users.
- [Environment-Specific Startup](./STARTUP_ENVIRONMENTS.md): Development, staging, and production startup patterns.
- [Docker Startup](./STARTUP_DOCKER.md): Startup with Docker Compose.
- [Startup Troubleshooting](./STARTUP_TROUBLESHOOTING.md): Common startup errors and fixes.

### Recommended Reading Order
1. Start with [Quick Test Startup](./STARTUP_QUICK_TEST.md).
2. Move to [Environment-Specific Startup](./STARTUP_ENVIRONMENTS.md) for your real environment.
3. Use [Docker Startup](./STARTUP_DOCKER.md) if you deploy in containers.
4. Check [Startup Troubleshooting](./STARTUP_TROUBLESHOOTING.md) when errors occur.

## 日本語

### 目的
初見ユーザでも迷わないように、起動手順を用途別に分離しています。

### ガイド一覧
- [Quick Test Startup](./STARTUP_QUICK_TEST.md): 初回確認向けの最短起動。
- [Environment-Specific Startup](./STARTUP_ENVIRONMENTS.md): 開発・ステージング・本番の起動方法。
- [Docker Startup](./STARTUP_DOCKER.md): Docker Compose での起動方法。
- [Startup Troubleshooting](./STARTUP_TROUBLESHOOTING.md): 起動時のよくあるエラーと対処。

### 推奨の読み順
1. まず [Quick Test Startup](./STARTUP_QUICK_TEST.md) を実行する。
2. 実運用前に [Environment-Specific Startup](./STARTUP_ENVIRONMENTS.md) を確認する。
3. コンテナ運用なら [Docker Startup](./STARTUP_DOCKER.md) を使う。
4. エラー時は [Startup Troubleshooting](./STARTUP_TROUBLESHOOTING.md) を参照する。
